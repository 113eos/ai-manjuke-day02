02 / 模式与工具

先判断素材，再选择生成模式

文生、图生和全能参考各有起点。按手头素材与镜头控制要求选择，工具入口和能力以当天实际页面为准。

三种生成模式，从不同素材开始

模式不是高低排序。先看你有什么素材、需要多少控制。

文生视频

从文字描述出发，适合快速试想法。

图生视频

从定稿图片出发，适合把角色或场景带入动作。

全能参考

组合多种素材，适合需要更多连续性控制的镜头。

实际产品支持哪些参考素材、参数和时长，以当天工具页面为准。

文生视频：先用文字验证画面想法

没有定稿参考图时，可以快速检查人物、场景和动作方向。

  • 适合：早期创意验证、气氛尝试、简单动作探索。
  • 先写：主体是谁、在哪里、做什么、镜头如何看。
  • 回看：结果不符合预期时，判断是主体、动作还是镜头要求含糊。

课程讲义把文生视频定位为前期验证方式；正式镜头仍需按项目要求决定是否使用参考图。

图生视频：从定稿画面延展动作

静态图是视觉起点，文字补充“接下来发生什么”。

图片负责人物外形、服装、场景与构图的参考
提示词负责动作顺序、表情、镜头运动和节奏

图片不会自动决定角色该怎么动。先确认参考图主体清楚，再用一两件明确动作引导视频。

全能参考：把多份素材按用途组合

人物、场景、道具、视频或声音参考都要说明各自负责什么。

  • 人物图：说明外形、服装或角色身份。
  • 场景图：说明空间、色调或构图基准。
  • 道具图：说明关键物件的形状、颜色和使用位置。
  • 视频或声音参考：只有在工具支持且课堂需要时使用，并标明要参考的节奏、动作或声音信息。

参考素材越多不代表结果越好；要检查素材之间是否冲突，生成后仍需逐项核对。

模式选择：沿着素材和用途做判断

一条简单的选型路线，先解决“从哪里开始”。

  1. 没有定稿人物或场景图？先用文生视频试创意。
  2. 已经有关键画面？先试图生视频，说明主体动作与镜头运动。
  3. 需要多角色、多场景或道具持续一致？评估是否需要全能参考，并确认平台能否提供相应入口。
  4. 正式交付？按客户要求、素材条件和工具限制确定组合方案。

这是本课的判断框架，不代表所有平台都有相同功能。

03 / 参数控制

控制清晰度、运动幅度和时长

每段视频先定清楚技术参数与动作范围。练习阶段遵循本课建议值，正式生成时再核对平台设置。

分辨率与帧率：先满足观看和交付用途

本课件的480p、720p、24–30fps与60fps是课堂参数例子，不是所有平台的固定规格。

分辨率

讲义示例：480p / 720p。测试阶段先保证能看清人物和动作。

帧率

讲义经验：24–30fps偏电影感，60fps运动更顺滑、文件也更大。

选择依据

查看生成入口可选规格，再按最终播放、剪辑和交付要求确定。

不同工具、模型、会员档位可能提供不同参数；以实际界面为准。

运动幅度与镜头时长：一次只做一件事

动作越复杂、镜头越长，越难保持人物与画面稳定。

低幅度

眨眼、转头、抬手。适合先做稳定性测试。

中幅度

走路、转身、坐下。适合常规剧情动作。

高幅度

跑、跳、打、快速转头。动作拆开生成，必要时分段。

讲义给出的练习时长：对话近景约3–5秒、动作中景约5–8秒、环境远景约5–10秒、情绪特写约3–5秒。先把它当作课堂起点，再按模型表现调整。

长镜头分段：拆动作，保留衔接依据

长镜头由多段短片接成；先让每一段只承担一个动作。

  1. 每段按课程建议控制在5–8秒，超过10秒时重点检查人物是否漂移。
  2. 每段只安排一个主要动作，不要一段里同时走、说、转身、换景。
  3. 段与段通过剪辑衔接；需要转场时选择明确的切镜或过渡。
  4. 保持人物定稿参考和关键视觉条件，生成后检查首尾动作是否接得上。

“同一张首帧”是原课给出的练习策略；若工具支持首尾帧或多关键帧，可依具体镜头另行设计。

04 / 景别与运镜

景别决定观众看什么，运镜决定怎样看

从环境、人物关系、动作和情绪选择景别，再把镜头运动写成明确的方向、速度与路径。

景别决定观众看什么

先用景别确定画面范围，再决定是否需要运镜。

景别画面范围主要任务
大远景人物很小交代宏大环境、氛围
远景人物约占画面一半环境过渡、空间衔接
大全景 / 全景多人关系 / 人物全身交代位置和肢体动作
中景膝盖以上推进日常叙事动作
近景 / 特写胸部以上 / 局部细节情绪、眼神、道具重点

别让整段戏只有一种景别。让镜头范围跟着信息重点变化。

环境镜头：大远景和远景负责交代空间

环境镜头先把观众带到故事发生的地方，然后尽快回到人物。

大远景人物在画面里很小

交代宏大环境、整体氛围，适合开篇或场景转换。

远景人物与环境同时可辨

用于连接场景或过渡节奏。讲义建议短剧环境镜头不要长停留。

写提示词时说明环境需要被看见的要素，以及镜头停留多久、接下来要切向哪里。

关系镜头：用大全景和全景交代人物位置

先让观众看懂谁在哪里，再进入对话和动作。

大全景整体场景与多人位置

多人出场、对话开始前，可以建立人物空间关系。

全景人物全身入画

走位、转身、坐下等肢体动作更容易被看清。

正式说戏时补充人物之间的距离、朝向和摄影机方位，避免人物叠在一起或被画面裁掉。

中景：推进剧情的常用叙事镜头

中景通常覆盖膝盖以上，适合看清动作，也保留人物表演。

  • 两个人日常对话。
  • 人物走路、转身、拿起物件等常规动作。
  • 剧情推进中的主要叙事镜头。

课程讲义把中景视为短剧常用、相对稳定的选择，并给出“可能占全片60%以上”的课堂观察值。具体比例要结合不同作品实际分析。

近景与特写：把情绪和关键线索推到观众面前

情绪变化、眼神和道具线索需要更近的画面范围。

近景胸部以上

刻画表情和情绪变化，适合哭、笑、愤怒等表演重点。

特写局部或关键细节

突出眼神、手部、信物或关键道具。

在情绪转折点使用近景或特写；如果人物动作很复杂，先简化动作再推进镜头。

运镜提示词要写路径，不只写“镜头动一下”

一个清楚的运镜说明，包含起点、方向、速度、主体关系和停止位置。

起点

镜头从哪里开始：全景、人物侧面、道具近景。

路径

摄影机如何移动：推近、侧移、跟拍、环绕。

节奏与终点

运动多快、何时停止、最后让观众看到什么。

按镜头任务选一种主要运动。复杂运动可以拆段做，再通过剪辑组合。

推、拉、摇、移、跟：五类常见镜头运动

用动词加方向和速度描述摄影机轨迹。

  • 推：由全景逐步靠近主体，强调人物或细节。
  • 拉：由特写或近景拉开，扩大空间信息。
  • 水平摇：摄影机位置基本不变，向左或向右扫过场景。
  • 垂直摇：从低处摇向高处，或从高处摇向低处。
  • 移：摄影机平稳侧移，交代空间或保持与主体的相对关系。
  • 跟：随人物移动，速度尽量匹配人物动作节奏。

升降、旋转与环绕：高动态镜头要给清楚边界

这些镜头能改变空间感，也更容易增加生成难度。

  • 升：从局部或低处逐渐升高，展开空间。
  • 降：从高处下降到人物或场景重点。
  • 旋转：描述旋转轴线、方向和速度；不要只写“旋转”。
  • 环绕：说明以谁为中心、从哪个方向绕行、是否持续看向主体。

旋转、环绕属于较复杂运动。先用短段验证人物和背景稳定性，再决定是否保留。

05 / 短剧节奏

用开场钩子和景别变化推进剧情

开篇先给观众继续看的理由；中段用景别变化服务冲突与情绪，镜头节奏跟着故事走。

开篇三秒：第一时间给观众一个继续看的理由

本课把“黄金钩子”作为短剧开场练习重点。

强冲突

人物正在对峙、争吵或做出决定。

强反差

身份、处境或画面预期突然反转。

强悬念

直接抛出一个观众想知道结果的问题。

不要慢慢铺垫到重点；开场情绪和画面信息要清楚。空镜、走路或单纯环境交代可以放到后续转场，不作为默认开篇。

短剧快节奏：景别变化跟着情绪走

镜头切换不是为了炫技，而是让观众跟上信息和冲突。

  1. 开篇用强信息画面建立钩子。
  2. 对话通常先用中景交代人物关系，关键情绪点切近景。
  3. 冲突升级时，可以从中景推进到近景，再到特写。
  4. 环境镜头用于必要的转场和空间交代，避免停留过久。
  5. 结尾用有信息的画面或反应收住本段，不要只为切镜而切镜。
06 / 角色一致性

让角色和场景在镜头之间接得上

重复使用定稿参考，固定人物、服装、场景和道具信息；多参考素材要有清楚分工。

每段视频从同一张定稿人设图开始

固定视觉参考能减少角色在不同镜头里被重新想象的机会。

  1. 先选清晰、完整、能代表角色的定稿图或三视图。
  2. 同一角色的不同镜头，尽量重复使用相同的核心参考。
  3. 提示词里保持姓名、发型、服装、年龄感等描述一致。
  4. 生成后对比脸型、发型、服装和关键配饰，不一致时先排查参考和描述是否冲突。

参考图不能保证每次生成都完全一致；它是稳定输入的一部分，还需要生成后检查。

多参考素材：先锁主体，再锁空间和道具

精品镜头可按需要组合角色、场景、道具和声音参考。

角色

人物定稿图或三视图。

场景

主场景的空间和色调参考。

道具

剧情关键物件及其外观。

声音

仅在工具支持时提供角色声音或氛围参考。

给每份素材写清用途。上传前检查清晰度和一致性；素材冲突时先删去无关参考。

07 / 提示词结构

按镜头复杂度，选择提示词层级

从单镜头公式，逐步扩展到多镜头时间轴与完整视听要求；先写清楚，再复制进工具。

L1：单镜头提示词，从五项基础信息开始

适合一条短视频镜头，先保证每项都能让别人想象画面。

主体 + 场景 + 动作 / 表情 + 镜头运镜 + 视觉风格
  • 主体是谁、有哪些需要保留的特征。
  • 场景在哪里，空间中有哪些重要物件。
  • 动作如何开始、发展、结束。
  • 摄影机从哪里看、怎样移动。
  • 整体画面风格是什么。

L2：多镜头短剧，用全局描述加时间轴

适合一段包含多个镜头的连续剧情。

全局描述 + 分镜编号与时间戳 + 每镜主体 / 场景 / 动作 / 风格

先写全片共同条件，再逐镜写不同动作和机位。标清每镜编号、起止时间、景别、运镜和动作，避免一大段文字里镜头切换不清。

切镜和时间戳的具体格式按生成工具要求调整。

L3：高阶提示词，把视听和约束放进同一结构

多镜头、参考素材和声音要求都重要时，再使用完整结构。

全局风格 + 参考素材 + 分镜时序 + 台词 + 音效 / BGM + 正向要求 + 负向约束

先把必需信息列齐，再删掉互相冲突或重复的描述。不要让提示词长到失去重点；最重要的镜头意图要放在清晰位置。

用一个动作检查提示词是否能执行

先读一遍提示词：动作顺序、镜头路径和结束状态是否清楚？

结构示例

“夜晚的花园中，女孩站在画面右侧。她先看向桌上的花，再伸手拿起花束。镜头从中景缓慢推近到近景，运动平稳，在她抬眼时停住。侧后方柔光，保持服装与发型参考一致。”

示例把主体、场景、动作顺序、运镜、停止位置和视觉条件分开说。它是课堂演示结构，不是固定咒语。

08 / 案例演示

看同一条提示词怎样落到视频里

下面五个案例都提供参考画面、提示词和课堂视频。观看时先找主体、动作、镜头运动和动态质感。

五个案例怎么读：先看素材，再看动作和镜头

每个示例都提供课堂视频。观察提示词里哪一项控制了画面变化。

参考图→动作→镜头运动→动态质感

观看时暂停一下：指出主体是谁、动作先后、镜头怎样走、成片是否保持了预期特征。

对照参考画面和提示词，找出动作与运镜的控制信息。

课堂提示词

课堂提示词

POV第一视角，手握方向盘，车快速行驶，镜头震动并带明显动态模糊。
09 / 逐镜生成

按分镜脚本一镜一镜生成和管理

生成前准备素材与镜头要求，生成后挑选、保存、排序，再进入剪辑。项目交付标准要与具体委托方约定一致。

逐镜生成：五步从分镜走到剪辑时间线

先按镜头准备和生成，不要把素材都攒到最后再整理。

  1. 确认镜头：读分镜，核对景别、运镜和时长。
  2. 准备参考：选择这一镜需要的人物、场景或道具图。
  3. 写提示词：按镜头模板补齐动作、摄影和视觉要求。
  4. 生成与筛选：按课堂流程生成1–3个候选，选一条最符合镜头意图的。
  5. 保存与剪辑：一镜一存，按顺序放入时间线，文件名保持可辨认。

竖屏短剧规格：先确认这是本项目的交付标准

以下数字来自课程原稿中的项目规范；更换项目时要先核对甲方要求。

分镜结构

原稿示例：每集7–8个分镜，每镜含2–4个Shot。

时长与画幅

单Shot不超过15秒；示例单集90–120秒；9:16竖屏满幅。

连续性规则

台词原文保留；OS为画外音时人物闭唇；注意轴线、道具连续和单镜主要运镜。

这些是课程中的项目参数，不是所有短剧、平台或客户都通用的统一规范。

10 / 瑕疵诊断

先判断问题，再针对性地修复

把画面异常归到扭曲、连续性错误或跳帧，再对应检查动作、时长、参考素材和镜头描述。

瑕疵排查：先描述看见了什么

先把问题说成可以观察的画面现象，再选择修复动作。

扭曲

手、脸、物体形状变形。

穿帮

场景、服装、道具或空间关系突然变化。

跳帧

动作、镜头方向、光线或背景突然跳变。

看问题时不要只说“效果不好”。描述发生在谁身上、哪个动作阶段、哪个画面细节。

人物或物体扭曲：减小动作并核对参考

常见表现包括手指粘连、五官错位、边缘拉丝或服装纹理乱跳。

  • 先把动作幅度降一档，复杂动作拆开。
  • 缩短单段时长；原课建议严重时可试5秒以内。
  • 尝试更清楚的主体画面或更稳定的景别。
  • 检查参考图是否清晰、完整，有无与文字描述冲突。
  • 负向约束可写清希望避免的画面问题，但仍要遵守平台使用规范。

人物变形的五类原因：逐项检查

对照生成条件排查，先改最明显的一项再重新生成。

  1. 动作幅度过大，例如跑、跳或快速转头。
  2. 单段太长，动作和镜头变化过多。
  3. 参考图与提示词的人物描述不一致。
  4. 参考图模糊、裁切或本身有不稳定细节。
  5. 运动方向与参考画面或人物姿态冲突。

穿帮：固定场景、道具和人物关系

常见现象是室内外切换、道具忽隐忽现、服装改变或左右关系翻转。

  • 重复使用同一套主要角色与场景参考。
  • 在描述里固定关键场景词和道具状态。
  • 每段只安排一项主要动作，避免叠加太多状态变化。
  • 出现轴线或左右关系问题时，检查机位和剪辑衔接。
  • 道具连续性要注明谁持有、何时拿起、何时放下。

跳帧：把动作、镜头和光线写成连续过程

跳帧会表现为姿势突变、镜头方向跳变、明暗闪烁或背景消失。

  • 动作过程拆清楚，必要时降低动作幅度。
  • 运镜说明加上“匀速、连续、平稳”等节奏要求。
  • 光线条件保持固定，不在一句提示词里突然改变光源。
  • 工具支持时尝试首尾帧或关键帧约束。
  • 若仍不连贯，将镜头拆段重新生成，再在剪辑中衔接。

六条生成检查：交付前逐项回看

课程原稿把这些列为制作硬规则；实际项目以确认过的脚本和交付要求为准。

  1. 单Shot时长符合项目限制，原稿示例为不超过15秒。
  2. 每镜标注景别与运镜。
  3. 色调、场景和镜头衔接服务于同一段剧情。
  4. 台词清楚注明角色归属，不擅自改写。
  5. 镜头有可见动作变化，避免整段只有静态摆拍。
  6. 涉及暴力或敏感题材时，使用克制、非血腥的视听表达；不要用替换词绕过平台审核。
11 / 四宫格体系

用起承转合预演四个关键画面

四宫格是分镜提示词工具：帮助把剧本或参考图转成四个画面计划，再交给生图工具生成预演图。

四宫格工具的角色：输出镜头提示词，不替你生成视频

它是一个视觉叙事提示词流程，用于预演镜头和整理生图提示词。

它负责梳理故事，拆成四个连续画面，输出可复制的文本提示词。
它不负责自动生成图片或视频，也不替导演决定最终镜头。

生成出的四宫格预演图可以交给相应的生图工具；实际工具操作以课堂准备的流程为准。

两种输入：一段剧本，或一张参考图

输入不同，先做的分析不同，最后都回到四个连续画面。

输入剧本提取主线、关键转折和人物关系

把剧情拆成起、承、转、合四个画面。

输入单张图解析人物、场景和氛围

以参考图为起点，设计一个完整的短篇过程。

标准输出：大纲、镜头拆解、最终提示词

固定输出有助于同组讨论和后续复制。

  1. 故事大纲：约100字，说明剧情主线与转折。
  2. 镜头拆解：列出起、承、转、合四个画面。
  3. 最终生图提示词：写明基础设定、统一风格、角色约束、限制条件和分镜详情。

四个画面形成一段完整叙事

起承转合不是四张互不相关的漂亮图，而是一个镜头计划。

起

建立人物，交代当下处境。

承

推进剧情，让关系或矛盾展开。

转

出现关键变化或情绪爆发。

合

收束这一段，留下结果或余韵。

每格要服务同一条故事线，并提前检查景别、站位和动作是否能衔接。

四宫格输出的六条约束

把格式、镜头信息和前后连续性写进提示词要求。

  1. 单镜头时长遵循项目限制，课程原稿示例为不超过15秒。
  2. 每镜标注景别和运镜。
  3. 风格、色调、场景与人物造型前后一致。
  4. 台词完整，并标清角色。
  5. 每个画面描述静态内容，也写出动态变化。
  6. 遵守内容平台和项目审核规则，使用克制、合规的表现方式。

分镜脚本八大模块：把镜头计划写完整

下面是可以复用的填空结构，时间轴是组织每镜动作的主线。

时间轴按秒组织景别、运镜、动作、音效和台词；其余模块保持全片设定一致。
